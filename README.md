# Fatimah Zahra Portfolio

A static portfolio website prepared for Vercel. No build command or framework is required.

## Deploy on Vercel

### Easiest method: GitHub + Vercel

1. Extract the ZIP file.
2. Create a new GitHub repository and upload everything inside this folder.
3. In Vercel, choose **Add New → Project** and import that repository.
4. Leave the framework preset as **Other**. No build command is needed.
5. Click **Deploy**.

### Without GitHub: Vercel CLI

1. Extract the ZIP and open a terminal in this folder.
2. Run `npx vercel --prod`.
3. Sign in when prompted and accept the suggested project settings.

Vercel's official deployment guide: https://vercel.com/docs/deployments/overview

The site can also be previewed locally by opening `index.html` in a browser.

## Main files

- `index.html` — content and structure
- `dark.css` — colours, typography and responsive layout
- `script.js` — menu, project popups and reveal animations
- `assets/` — project screenshots, résumé and favicon
